# CG_Project
# Animated Landscape Scene using OpenGL

This project was developed using C++ and OpenGL (GLUT). It demonstrates an interactive 2D landscape with animations and user controls.

The application features a rotating windmill, moving clouds, a house, trees, hills, and other graphical objects. It also supports keyboard controls for starting, stopping, and manually rotating the windmill.

This project showcases computer graphics concepts such as 2D transformations, timer-based animation, and double buffering for smooth rendering.


## Tech Stack

- **Language:** C++
- **Graphics Library:** OpenGL
- **Toolkit:** GLUT (FreeGLUT)
- **IDE:** Visual Studio Code
- **Compiler:** g++

## Features

- Animated rotating windmill
- Moving clouds
- Interactive keyboard controls
- 2D transformations (Rotation & Translation)
- Smooth animation using timer callbacks
- Double buffering for flicker-free rendering

## Controls

| Key | Function |
|------|----------|
| **S** | Start/Stop animation |
| **R** | Rotate windmill clockwise |
| **L** | Rotate windmill counter-clockwise |
